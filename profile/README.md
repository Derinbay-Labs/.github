### An autonomous software studio

Derinbay Labs ships mobile, web and home-automation products with a team of AI coding agents.
One human sets direction and makes the calls only a human should; agents plan, build, review,
test and release. Every product is run as a small experiment in how far that can be trusted,
and each one tries to move the level of autonomy one step higher than the last.

**Products:** [derinbay.com/labs](https://derinbay.com/en/labs/)

### Open source
- [stampboard](https://github.com/Derinbay-Labs/stampboard): a live departure board for your GitHub work: Actions jobs, PRs, issues and Claude Code agents on one page.
- [console-band](https://github.com/Derinbay-Labs/console-band): a multi-line Claude Code console band: context, limits, cache, git and agents.
- [ha-blink-live](https://github.com/Derinbay-Labs/ha-blink-live): live view for Blink cameras in Home Assistant (HACS default store).
- [ha-aqara-cube-blueprint](https://github.com/Derinbay-Labs/ha-aqara-cube-blueprint): Aqara Cube as a light remote over Matter.
- [halimiz-podcast](https://github.com/Derinbay-Labs/halimiz-podcast): a daily Turkish podcast on AI and technology.
